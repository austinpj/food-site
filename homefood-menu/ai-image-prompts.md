# AI Image Prompts

Paste any prompt below into a free AI image generator (Bing Image
Creator, ChatGPT, Leonardo.ai, etc.), save the result using the exact
filename given, and drop it into `public/images/`. Then update the
matching `"image"` field in `public/data/dishes.json` (or the HTML
location noted in `README.md` for the 3 hero photos) to
`images/<filename>`.

Shared style note baked into every prompt: warm, natural light,
overhead or 45-degree angle, shallow depth of field, realistic
professional food photography (not illustration/cartoon), served on
simple rustic tableware, no text or watermarks.
